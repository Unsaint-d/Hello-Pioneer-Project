# Hello Pioneer Project

**Hello Pioneer Project** — это комплексная универсальная система для автоматизации задач мониторинга, поисково-спасательных операций и охраны территории.

Проект был вдохновлен необходимостью повышения эффективности поиска пропавших людей и автоматизации патрулирования частных территорий. Система призвана снизить трудоемкость этих задач за счет использования автономных дронов и технологий компьютерного зрения.

## 🚀 О проекте

### Проблема
Ручное патрулирование территорий и поисковые операции — это трудоемкие и ресурсозатратные процессы. Человеческий фактор, усталость и ограниченный обзор затрудняют эффективный поиск и мониторинг.

### Решение
Комплекс, способный автономно патрулировать заданную территорию, обнаруживать людей и передавать данные оператору. Система объединяет управление дроном, планирование миссий и интеллектуальный анализ видеопотока.

### Целевая аудитория
*   **Спасатели и службы экстренного реагирования** — для поиска людей.
*   **Службы охраны** — для автоматизированного патрулирования периметра.
*   **Студенты и образовательные учреждения** — для изучения робототехники и компьютерного зрения.
*   **Энтузиасты и разработчики** — как платформа для экспериментов.

## 🏗 Архитектура системы

Проект состоит из трех ключевых модулей:

### 1. Frontend (Станция управления)
Веб-интерфейс для взаимодействия с системой.
*   **Функции:** Создание планов полета и маршрутов (с экспортом в JSON).
*   **Управление:** При наличии дрона линейки **Геоскан Пионер**, выступает как полноценная наземная станция управления (GCS) с доступом к консоли дрона и телеметрии.
*   **Универсальность:** Может использоваться отдельно как инструмент планирования.

### 2. Backend (Ядро системы)
Центральный узел, связывающий все компоненты.
*   **Функции:** Управление дроном, обработка входящих данных, API для фронтенда.
*   **Совместимость:** На данный момент полностью интегрирован с дронами **Геоскан Пионер**.

### 3. Computer Vision (Система компьютерного зрения)
Модуль интеллектуальной обработки видео.
*   **Функции:** Детекция людей и распознавание лиц в реальном времени.
*   **База данных:** Сравнение обнаруженных лиц с локальной базой фотографий для идентификации.
*   *Примечание: В будущем планируется полная интеграция этого модуля в виде плагина.*

*   **Распознавание лиц в реальном времени** — мгновенная идентификация людей в кадре.

## 📥 Установка и запуск

*Перед началом работы убедитесь, что у вас установлены необходимые инструменты.*

### Предварительные требования

*   **Python 3.12+**: [Скачать с python.org](https://www.python.org/downloads/)
*   **Node.js & npm**: [Скачать с nodejs.org](https://nodejs.org/en/download/)

### 🛠️ Инструкция по установке

#### 1. Клонирование репозитория
```bash
git clone https://github.com/ВашЮзернейм/Hello-Pioneer-Project.git
cd Hello-Pioneer-Project
```

#### 2. Настройка Backend

**Windows:**
```powershell
cd backend
# Создание виртуального окружения
python -m venv .venv
# Активация окружения
.venv\Scripts\activate
# Установка зависимостей
pip install -r backend_requirements.txt
```

**Linux / macOS:**
```bash
cd backend
# Создание виртуального окружения
python3 -m venv .venv
# Активация окружения
source .venv/bin/activate
# Установка зависимостей
pip install -r backend_requirements.txt
```

#### 3. Настройка Frontend

Независимо от ОС, команды выполняются одинаково (требуется установленный Node.js).

```bash
cd ../frontend
# Установка зависимостей
npm install
```

### ▶️ Запуск

1.  **Запустите Backend:**
    В терминале с активированным venv (в папке `backend`):
    ```bash
    python main.py
    ```

2.  **Запустите Frontend:**
    В новом терминале (в папке `frontend`):
    ```bash
    npm run dev
    ```
    Откройте ссылку, которая появится в консоли (обычно `http://localhost:5173`).
